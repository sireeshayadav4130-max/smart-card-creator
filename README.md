# Live Interactive Card Builder

A responsive website based on the **DOM Events Assignment: Live Interactive Card Builder**.

## Files
- `index.html` — website structure
- `style.css` — layout and colours
- `script.js` — live preview, category change, add-card and delete-card events

## How to run
1. Download or extract this ZIP file.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a web browser.

## GitHub Pages
1. Create a GitHub repository.
2. Upload the three website files (or upload the ZIP if you only need to store the project).
3. For a live website, extract the ZIP first and upload `index.html`, `style.css`, and `script.js` to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. Wait for deployment; GitHub Pages will show the website URL in the Pages section.

## Features
- Live title preview as you type
- Personal, Work and Urgent categories with different colours
- Add cards to the saved cards section
- Delete cards
- Responsive layout for mobile and desktop
